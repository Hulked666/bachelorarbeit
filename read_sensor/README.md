# STM32 Weather Station – Bachelor Thesis Project

This repository contains the embedded software developed as part of my
Bachelor's thesis.

The objective of the thesis is the development of a weather station based
on an STM32 microcontroller. The system acquires environmental data using
a BME280 sensor and displays the processed measurements on a TFT display.

## Technologies

- Embedded C
- STM32
- STM32 HAL
- I2C
- SPI
- UART
- Git

## Driver Development

As part of the thesis, I am implementing the required embedded software
and hardware drivers, including:

- STM32L476RG Microcontroller
- BME280 sensor communication via I2C
- TFT display communication via SPI
- Register-level device communication
- Buffered display data transmission
- Error handling and hardware/software debugging

The project is currently under active development.
